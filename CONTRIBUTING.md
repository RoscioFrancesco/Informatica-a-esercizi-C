# Contribuire

Per segnalare un problema indica:

- ID e percorso dell'esercizio.
- Compilatore e comando utilizzati.
- Input minimo che mostra il problema.
- Output osservato e output atteso, con una spiegazione.

Una correzione dovrebbe riguardare un singolo esercizio e conservare i commenti di provenienza utili. Spiega quale comportamento corregge e come lo hai verificato. Se proponi un algoritmo alternativo, presentalo come variante distinguibile.

Le categorie automatiche possono essere migliorate. Nel farlo, aggiorna anche l'indice e il catalogo, così il sorgente rimane trovabile attraverso il suo ID originale.
