# Date e numerazione

[README](README.md) · [Indice](INDICE.md)

I file sono suddivisi in 11 sezioni numerate. All’interno di ogni sezione la numerazione riparte da 001 e segue l’ordine cronologico completo (anno, mese, giorno). A parità di data si usa l’ordine naturale del titolo. I file senza data vengono dopo quelli datati.

Formato del nome: `001_25-09_titolo-del-programma.c`. Le date provengono dalle intestazioni dei sorgenti; l’anno è conservato nel catalogo.

**860 file con data; 6 file senza data.** Per questi ultimi il nome contiene `data-non-indicata`, così non viene attribuita una data non verificabile.
